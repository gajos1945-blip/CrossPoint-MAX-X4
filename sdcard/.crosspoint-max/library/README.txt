CrossPoint MAX Library v1.4-dev

The firmware creates:
  /.crosspoint-max/library/index.jsonl

Recommended book layout:
  /Books/<Collection>/<Series>/<book.epub>

Example:
  /Books/Fantasy/Wiedzmin/Ostatnie zyczenie.epub

Collection = Fantasy
Series = Wiedzmin

Do not manually edit index.jsonl while the X4 is using the SD card.
